# CAD Drawing Automation

A Python-based CAD automation system for generating and modifying engineering drawings in DXF format using predefined geometry, dimensional rules, and engineering logic.

## Overview

This project automates repetitive CAD drawing operations and generates DXF drawings based on predefined engineering parameters and rules.

The system is designed to reduce manual drafting work, improve consistency, and speed up the generation of engineering drawings.

## Key Features

- Automated CAD drawing generation
- DXF file creation and modification
- Parametric geometry handling
- Automated dimensions and annotations
- Engineering-rule-based drawing logic
- Automated modification of drawing components
- PNG preview generation from DXF files
- Support for reusable drawing templates

## Technologies Used

- Python
- DXF
- AutoCAD
- CAD Automation
- Computational Geometry
- Parametric Design
